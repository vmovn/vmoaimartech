# Skill: UI Change

1. Read `DESIGN.md`.
2. Inspect 2–3 nearest comparable screens/components.
3. Reuse `src/components/ui` and shared patterns.
4. Use semantic tokens from `src/styles.css`.
5. Preserve responsive/loading/empty/error patterns.
6. Do not introduce design-system changes unless task explicitly requires them.
7. Run relevant design audits from package scripts when available.
