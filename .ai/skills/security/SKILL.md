# Skill: Security

Threat-check:
- tenant isolation;
- authorization/RBAC;
- RLS;
- secret exposure;
- webhook authenticity;
- injection/XSS;
- mass assignment;
- privileged functions/search_path;
- idempotency/replay;
- audit trail.

Security fix should create/extend a regression check whenever practical.
Do not weaken existing security to make a feature pass.
