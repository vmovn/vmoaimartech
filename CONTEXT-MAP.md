# Context Map

Read the relevant context before modifying its domain.

| Context | Path | Owns |
|---|---|---|
| Platform | `docs/contexts/platform/CONTEXT.md` | organization, workspace, membership, RBAC, settings, billing boundaries |
| Identity | `docs/contexts/identity/CONTEXT.md` | canonical contacts, channel identities, merges, identity resolution |
| CRM | `docs/contexts/crm/CONTEXT.md` | leads, companies, deals, pipeline, lifecycle, scoring/segmentation |
| Messaging | `docs/contexts/messaging/CONTEXT.md` | channels, accounts, conversations, messages, delivery states, inbox |
| Workflow | `docs/contexts/workflow/CONTEXT.md` | triggers, actions, workflow runtime, runs/steps, external execution |
| Vietnam | `docs/contexts/vietnam/CONTEXT.md` | localization, Zalo, VN conventions and local integrations |

Cross-context changes should state which context owns the new concept and which contexts only consume it.
