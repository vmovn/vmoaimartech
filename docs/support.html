Before you open a ticket

  • Confirm your version on the Changelog page and update if you are behind.
  • Check the System Status page and Super Admin → System Health.
  • Re-read the relevant section of the documentation — most issues are configuration related.

What to include

  • Swiffer version and whether you run the hosted or self-hosted build.
  • Hosting environment (Node.js version, cPanel/LiteSpeed, Docker, etc.).
  • Exact steps to reproduce, plus the full error message or screenshot.
  • Browser console and server log output around the time of the error.
  • Affected channel (WhatsApp, Messenger, Instagram, Telegram, Live Chat, Email, SMS), if applicable.

Never share secrets. Do not paste API keys, app secrets, access tokens, database passwords, or service-role keys in a ticket.

Scope of support

  • Included: bug fixes, installation assistance, configuration guidance, and help with documented features.
  • Not included: custom development, third-party plugin conflicts, server administration, and Meta/Telegram account approvals.

Common questions

Installation is stuck on license activation. Complete the Setup Wizard first — the super admin is bootstrapped before activation.

WhatsApp messages fail with error #131030. The recipient is not in your Meta test-number allow list; add the number or move the app out of sandbox mode.

Messenger or Instagram will not connect. Store your Meta App ID and Secret in the Meta App settings screen, then confirm the OAuth redirect URIs match exactly.

How do I reset the setup wizard? Delete the setup_complete platform setting row, then reload the app.
