# Vietnam Context

## Purpose
Vietnam-specific differentiation without contaminating generic core concepts.

## Owns
- Vietnamese localization and terminology
- `+84` phone normalization/display conventions
- VND formatting and Vietnam timezone defaults where product policy chooses them
- Zalo OA/ZBS/Zalo ecosystem adapters
- Local business templates/onboarding
- Future validated local payment/accounting/invoice/tax integrations

## Boundary rule
Vietnam context may extend generic provider/domain interfaces but should not fork generic CRM, identity or workflow semantics solely for local naming.
