<h2>Multi-Role System</h2>
<p align="center">
  <img src="/marketing/role-agent.jpg" alt="Agent Role" style="max-width:32%; border-radius: 8px; margin: 4px;"/>
  <img src="/marketing/role-manager.jpg" alt="Manager Role" style="max-width:32%; border-radius: 8px; margin: 4px;"/>
  <img src="/marketing/role-admin.jpg" alt="Admin Role" style="max-width:32%; border-radius: 8px; margin: 4px;"/>
</p>
<ul>
  <li><strong>Super Admin</strong> — platform-wide operations, tenants, billing, branding, PWA icons, AI providers and payment gateways.</li>
  <li><strong>Owner / Admin</strong> — full workspace control, members, roles, billing.</li>
  <li><strong>Agent</strong> — inbox, CRM, sales, helpdesk, campaigns.</li>
  <li><strong>Provider</strong> — restricted delivery / logistics / partner surfaces.</li>
  <li><strong>User / Viewer</strong> — read-only or personal scope.</li>
</ul>
<p>All roles are stored in a dedicated <code>user_roles</code> table and enforced through a <code>has_role()</code> SECURITY DEFINER function plus strict Row Level Security — no client-side role checks, no privilege escalation.</p>

<h2>Authentication System</h2>
<ul>
  <li>Supabase Auth with email/password and social OAuth (Google, Apple, Microsoft-ready).</li>
  <li>Secure PasswordInput component with strength meter.</li>
  <li>Invitation flow with role presets and email delivery.</li>
  <li>Multi-tenant workspace switching with cache purge and realtime resubscribe.</li>
  <li>Idle-logout, session rotation, device management and biometrics (mobile).</li>
</ul>

<h2>Role-Based Redirect System</h2>
<ul>
  <li>Post-login routing decided by role and workspace context.</li>
  <li>Super Admin → <code>/admin</code>, Agent → <code>/inbox</code>, User → <code>/dashboard</code>, Provider → dedicated console.</li>
  <li>Deep-link protection: unauthorized hash and route deep links never render protected panels — verified with end-to-end tests.</li>
  <li>Account menu items are hidden or disabled per role in sidebar and mobile navigation.</li>
</ul>
